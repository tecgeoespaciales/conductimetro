INSTALACIÓN DE LA APLICACIÓN CONDUCTÍMETRO (WINDOWS Y LINUX)
===========================================================

Este proyecto es una aplicación de escritorio en Python (PyQt5) que se ejecuta desde el archivo `main.py`.

Dependencias Python del proyecto:
- PyQt5>=5.15.0
- pyserial>=3.5
- pyqtgraph>=0.12.0
- matplotlib>=3.5.0
- numpy>=1.20.0

-----------------------------------------------------------
1) REQUISITOS PREVIOS
-----------------------------------------------------------
- Tener Python 3.7 o superior instalado (recomendado: 3.10+).
- Tener `pip` disponible.
- Tener conectado el dispositivo ESP32 por USB (si vas a usar comunicación serial).

Verificar versión de Python:
- Windows: `py --version`
- Linux: `python3 --version`

-----------------------------------------------------------
2) INSTALACIÓN EN WINDOWS
-----------------------------------------------------------
2.1. Abrir PowerShell en la carpeta del proyecto.

2.2. Crear entorno virtual:
`py -m venv venv`

2.3. Activar entorno virtual:
`venv\Scripts\Activate.ps1`

Si PowerShell bloquea scripts, ejecutar una vez:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

2.4. Actualizar herramientas base:
`python -m pip install --upgrade pip setuptools wheel`

2.5. Instalar dependencias del proyecto:
`pip install PyQt5 pyserial pyqtgraph matplotlib numpy`

2.6. Ejecutar aplicación:
`python main.py`

-----------------------------------------------------------
3) INSTALACIÓN EN LINUX (Ubuntu/Debian)
-----------------------------------------------------------
3.1. Abrir terminal en la carpeta del proyecto.

3.2. Instalar paquetes del sistema (si no están):
`sudo apt update`
`sudo apt install -y python3 python3-venv python3-pip`

3.3. Crear entorno virtual:
`python3 -m venv venv`

3.4. Activar entorno virtual:
`source venv/bin/activate`

3.5. Actualizar herramientas base:
`python -m pip install --upgrade pip setuptools wheel`

3.6. Instalar dependencias del proyecto:
`pip install PyQt5 pyserial pyqtgraph matplotlib numpy`

3.7. Ejecutar aplicación:
`python main.py`

-----------------------------------------------------------
4) PERMISOS DE PUERTO SERIAL EN LINUX
-----------------------------------------------------------
Si la app no puede abrir el puerto serial, agrega tu usuario al grupo `dialout`:
`sudo usermod -aG dialout $USER`

Luego cierra sesión y vuelve a entrar (o reinicia).

-----------------------------------------------------------
5) SOLUCIÓN DE PROBLEMAS RÁPIDA
-----------------------------------------------------------
A) Error de módulo no encontrado:
- Verifica que el entorno virtual esté activado.
- Reinstala dependencias con el comando de la sección 2.5 o 3.6.

B) Error de Qt en Linux (plugin xcb):
- Instala librerías adicionales:
`sudo apt install -y libxcb-xinerama0 libxkbcommon-x11-0 libgl1`

C) No detecta el ESP32:
- Cambia cable USB.
- Verifica el puerto COM/ttyUSB.
- Cierra otros programas que estén usando el mismo puerto.

-----------------------------------------------------------
6) DESACTIVAR ENTORNO VIRTUAL
-----------------------------------------------------------
Para salir del entorno virtual en cualquier sistema:
`deactivate`

-----------------------------------------------------------
7) EJECUCIÓN DIARIA (RESUMEN)
-----------------------------------------------------------
Windows:
1. `venv\Scripts\Activate.ps1`
2. `python main.py`

Linux:
1. `source venv/bin/activate`
2. `python main.py`
